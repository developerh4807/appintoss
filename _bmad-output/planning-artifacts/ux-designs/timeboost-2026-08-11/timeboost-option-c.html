시안 C — 스테이지 시작 브리핑 카드 (Pre-Stage Briefing)

접근 방식: 게이지를 꾸미는 대신 스테이지가 시작되기 직전에 화면을 한 번 멈춰서 "이번 스테이지는 15초 → 20초로 시작합니다"를 큰 숫자로 못 박고, 플레이어가 직접 시작 버튼을 눌러야 타이머가 돈다.
색 외 신호: 큰 숫자 15→20(텍스트) · 취소선(형태) · 화살표(아이콘) · 브리핑 게이지와 게임 게이지의 동일한 형태 연결 · 게이지 위 "원래 15초" 앵커 마커(형태+텍스트).
타이머는 브리핑이 닫히는 순간부터 시작 — 기존 코드의 "클리어 다이얼로그 동안 타이머가 몰래 돌지 않는다" 원칙과 동일한 구조.

시작을 누르기 전까지 시간은 흐르지 않아요.
브리핑 카드 안의 게이지는 실제 헤더 게이지와 똑같은 모양·같은 위치 폭이라, 카드가 사라지면 시선이 그대로 헤더 게이지로 이어진다. 게이지 위의 "원래 15초" 앵커 마커는 게임 중에도 남아서, 시간이 줄어드는 내내 "지금 저 마커보다 오른쪽 = 아이템이 준 시간"이 계속 읽힌다. 타이머는 시작하기를 누른 뒤에 돈다.
