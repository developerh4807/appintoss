# 카피 사례 로그

통과·반려 실물 기록. 새 카피를 쓸 때 문형을 참고하고, 반례로 자가 검수한다.
**새 소재를 제출할 때마다 결과를 여기에 추가한다.**

## 스마트발송 광고성 푸시

### 1차 등록 (2026-09-12) — 3전 2패

| 시도 | 제목 | 본문 | 결과 |
|---|---|---|---|
| a안 | 잠깐 두뇌휴식 | 동물 짝 맞추기로 잠깐 머리 식혀요. | ✅ 1차 통과 |
| b안 1차 | — | 틀리면 끝.. 어디까지 가는지 확인해 봐요. | ❌ 불안감 조성 + 범용 문구 |
| b안 2차 | — | 동물 짝 맞추기, 몇 단계까지 갈 수 있나요 | ❌ 질문형 + 다음 화면 예측 어려움 |
| b안 3차 | 동물찾기 도전 | 동물 짝을 맞춰 다음 스테이지로 가 봐요. | ✅ 3차 통과 |

**여기서 나온 규칙**: 의문문 금지, 위협 프레임 금지, 말줄임표 금지, 소재 명시 필수

> ⚠️ a안 "잠깐 머리 식혀요"는 **심사는 통과했지만 제품과 불일치한다.**
> 이 게임은 5초 타이머·전면 리셋 구조라 "머리 식히기"가 아니다.
> 심사 통과와 좋은 카피는 다른 문제다.

### 2차 수정 (2026-09-15) — 명령형 반려

| 안 | 본문 | 결과 |
|---|---|---|
| a·b 공통 | `~해 보세요.` 종결 | ❌ **둘 다 반려** — 명령형 |

수정 후:

| 안 | 제목 | 본문 | 결과 |
|---|---|---|---|
| a안 | 매칭 게임 | 동물 짝을 맞춰 다음 스테이지로 가 봐요. | ✅ 통과 |
| b안 | 기록 도전 | 동물 짝 맞추기로 내 최고 기록을 세워 봐요. | ✅ 통과 |

**🚫 이 2안이 실패한 이유 (심사와 무관)**

- **축이 갈리지 않았다** — 사실상 같은 말의 변주. AI에게 준 선택지가 하나였다
- **제목에 후킹이 없다** — "매칭 게임" 네 글자로는 스크롤이 멈추지 않는다
- **숫자가 0개** — 구체성 없음

→ 통과했지만 CTR 0%, 발송량도 62 → 100건 미만으로 정체.

**교훈: 명령형 규칙은 3일 전 노트에 이미 적혀 있었는데 놓쳐서 반려됐다.**
노트의 가치는 작성이 아니라 재사용에 있다. 이 스킬이 그 재사용 장치다.

### 3차 수정 (2026-09-17) — 제목 중심 재설계 ⭐ 현행

| 안 | 제목 | 본문 | 축 | 결과 |
|---|---|---|---|---|
| a안 1차 | 기억력 테스트 (7자) | 스테이지 **9**부터 동물이 변장하고 나와요. (21자) | 호기심 | ✅ 심사 통과 / ❌ **사실 오류** |
| a안 2차 | 기억력 테스트 (7자) | 스테이지 **10**부터 동물이 변장해요. (19자) | 호기심 | ✅ 확정 |
| b안 1차 | 내 등급 확인 (6자) | 동물 짝 맞추기 최고 등급은 치타급이에요. (23자) | 자기 검증 | ❌ **제목 명사형 위반** |
| b안 2차 | **내 동물 등급** (6자) | 동물 짝 맞추기 최고 등급은 치타급이에요. (23자) | 자기 검증 | ✅ 확정 |

**여기서 나온 규칙**: 제목 순수 명사 종결, `~이에요` 평서 종결 허용

**사실 근거**
- `스테이지 10` → `balance.ts:100` disguiseCountForStage (stage >= 10 → 2종)
- `치타급` → `leaderboard.ts:48` TIERS 최상위 (minStage 20)

### 🚨 a안 사실 오류 — 심사는 통과했지만 거짓이었다

초안은 `스테이지 9부터 동물이 변장하고 나와요.`였다. **심사를 통과했다.**
제출 후 체크리스트로 자가 검수하다가 잡혔다.

`balance.ts:100` 실제 값:

| 스테이지 | 변장 종수 |
|---|---|
| ~9 | **0 (변장 없음)** |
| 10~12 | 2 |
| 13~15 | 3 |
| 16~ | 4 |

**변장은 스테이지 10부터다.** 9를 쓴 것은 티어 경계(사슴급 `minStage: 9`)와 혼동한
결과다. 두 숫자가 가까워 검증 없이 넘어갔다.

**교훈 세 가지:**

1. **심사 통과는 사실 검증이 아니다.** 심사 AI는 형식만 본다. 거짓 사실은 그대로 나간다
2. **비슷한 숫자가 코드 여러 곳에 있으면 반드시 혼동한다.** 이번 건은 변장 구간(10)과
   티어 경계(9)가 1 차이였다. 숫자를 쓸 때는 **해당 함수를 직접 열어 확인**한다 —
   기억이나 근처 파일의 다른 숫자로 대체하지 않는다
3. **자수도 기계로 센다.** 21자로 알고 있었으나 실제 19자, b안은 22자로 알았으나 23자였다.
   눈으로 세면 틀린다

```python
# 자수·형식 일괄 확인
python3 -c "
b='스테이지 10부터 동물이 변장해요.'
print(len(b), b.endswith('.'), '?' in b, '..' in b)
"
```

> 💡 이 오류는 스킬 체크리스트의 "숫자·단정 표현의 근거를 코드에서 확인했는가" 항목이
> 잡아냈다. 체크리스트가 실제로 작동한 첫 사례다.

**예비안 (미사용)**
```
c안  내 동물 등급 / 동물 짝 맞추기로 치타급에 도전해 봐요.  (22자)
d안  기억력 테스트 / 스테이지 9면 제한시간이 9초예요.       (19자)
```

## ❌ 기각된 카피와 그 이유

심사에 낸 적 없이 작성 단계에서 버린 것들. **같은 실수를 반복하지 않기 위한 반례다.**

### 숫자는 있는데 장면이 없다

```
❌ 평균 3스테이지        대시보드 지표 같다. 사람이 쓰는 말이 아니다
❌ 15초 기억력           명사 두 개를 붙였을 뿐 문장이 아니다
❌ 15초 기억력 테스트     10자 — 제목 상한 초과
```

**구체성 = 숫자 삽입**으로 오해하면 이렇게 된다.
숫자를 넣으려다 말이 어색해지면 숫자를 포기하는 게 맞다 —
`기억력 테스트`(제목, 숫자 없음) + `15초 안에…`(본문, 숫자 있음)로 분산한 이유다.

### 답을 다 말해서 궁금증이 죽었다

```
❌ 대부분 스테이지 3에서 멈춰요.
```

정보를 완결해서 클릭할 이유가 사라졌다.
→ `스테이지 10부터 동물이 변장해요.`는 "어떻게 변장?"을 남긴다.

### 허위 소구

```
❌ 스테이지 9까지 가면 상위 1%
```

| 문제 | 근거 |
|---|---|
| 측정 불가 | 순위 조회 API 없음 (`leaderboard.ts` 주석 — `openGameCenterLeaderboard()`는 `Promise<void>`) |
| 모수 8명 | 1% = 0.08명 |
| 법적 리스크 | 표시광고법상 실증 책임 대상 |

**"소명할 일 없으니 괜찮다"는 성립하지 않는다** — 아무도 묻지 않아야 한다는 조건을
우리가 통제할 수 없고, 무엇보다 클릭한 사람이 존재하지 않는 걸 근거로 클릭하게 된다.

💡 **대체안이 더 강했다.** `동물이 변장하고 나와요`는 즉시 장면이 그려진다.
사실 제약은 창의성의 적이 아니다.

### 제품과 불일치

```
❌ 모은 재화로 동물 아이템을 뽑아 봐요.   (가챠 소구, 신규 유입용)
```

| 문제 | 근거 |
|---|---|
| 첫 화면에 없다 | 뽑기 12재화 / 클리어당 10재화 → **후반 콘텐츠** |
| 후킹 약함 | "동물 아이템 뽑기"는 흔한 모바일게임 문구 |
| 제목과 불일치 | 제목이 기억력인데 본문이 가챠면 메시지가 둘 |

첫 화면에 없는 걸 미끼로 쓰면 클릭해도 못 찾고 이탈한다.
→ **가챠는 기능성 푸시(재방문)로 이전.** 재화를 모아둔 유저에겐 실제 경험과 일치한다.

```
❌ 잠깐 머리 식혀요   (심사는 통과했으나 제품과 불일치)
```

5초 타이머·전면 리셋 게임에 "휴식" 소구는 CTR↑ 리텐션↓의 전형이다.
