# 채널별 제약

카피를 쓰기 전에 해당 채널 항목을 읽는다. 글자 수·심사 여부·톤 허용 범위가 채널마다 다르고,
특히 **심사 채널과 비심사 채널의 톤 자유도 차이가 크다.**

## 한눈에 보기

| 채널 | 심사 | 글자 수 | 톤 자유도 | 상태 |
|---|---|---|---|---|
| 스마트발송 광고성 푸시 | ✅ 자동 | 제목 7 / 본문 25 | 낮음 | **2026-10-01 종료** |
| 스마트발송 기능성 푸시 | ✅ 템플릿 | 동일 추정 | 낮음 | 유지 |
| 결과 카드 | ❌ | 제약 없음 (UI 레이아웃) | **높음** | 상시 |
| 공유 문구 | ❌ | 제약 없음 (메신저) | **높음** | 상시 |
| 스토어 등록정보 | ✅ 스토어별 | 스토어 규정 | 중간 | 상시 |

**심사 없는 채널(결과 카드·공유 문구)이 도발·승부욕 톤의 본진이다.**
광고 푸시에서 못 쓰는 표현을 여기서 쓴다.

---

## 스마트발송 광고성 푸시

> ⚠️ **2026-10-01부터 종료됐다.** 아래는 기록 목적 + 기능성 푸시에 규칙을 이전하기 위한 것이다.

### 글자 수

- 제목 **7자**, 본문 **25자** (둘 다 공백 포함)
- `(광고)` 접두와 `* 알림 끄기는 토스 앱 설정에서` 꼬리말은 **플랫폼이 자동으로 붙는다** —
  우리 글자 수에 포함되지 않는다
- **상한을 꽉 채우지 않는다.** 19~22자가 안전권. 반려 후 수정할 여유를 남긴다

### 실제로 보이는 것

```
제목: 기억력 테스트
본문: (광고) 스테이지 9부터 동물이 변장하고 나와요.
                        └─ 큰글자모드에서 이 뒤가 잘릴 수 있음
```

안드로이드 67% + 큰글자모드 25%. **제목이 후킹을 담당하고 본문은 보조다.**
제목이 스크롤을 멈추게 하지 못하면 본문은 읽히지도 않는다.

### 콘솔 설정

| 항목 | 설정 | 근거 |
|---|---|---|
| 소재 개수 | **2개** | AI가 pCTR로 자동 배분. 1개면 그 기능을 끄는 것 |
| 클릭 시 URL | 홈 화면 | 소재별 다른 URL 불가 |
| 종료일시 | **21:00으로 맞춘다** | 방해금지(21~08시) 때문. 아래 참조 |
| 발송 대상 | 나이 조건 필수 | UI상 필수 — 비우면 알럿 (문서와 다름) |
| 성별 | 걸지 않는다 | 절반이 날아간다 |

### ⚠️ 방해금지 시간 (21~08시)

푸시가 발송되지 않고, 이 시간에 못 보낸 푸시는 **다음 날 08시에 발송**된다.

- 종료일시를 19:35 같은 기본값으로 두면 **저녁 황금시간대를 통째로 버린다**
- 마지막 날 밤에 밀린 푸시는 다음 날로 넘어가 **캠페인 종료일이면 안 나간다**

### 🚨 수정 차단 함정 (공식 문서에 없음)

소재 문구를 수정하려 하면 `해당 템플릿 그룹에 예약된 메시지가 있습니다` 에러가 난다.
**발송 중단해도 해소되지 않는다.**

```
확정된 수정 절차:
1. 소재 발송 중단          ← 수정 화면 진입의 필요조건
2. 21시 이후까지 대기       ← 시간 조건이 추가로 필요
3. 수정 → 재검수 제출
```

메커니즘: 예약된 메시지는 **끝까지 취소되지 않는다.** 큐가 비길 기다리는 게 아니라,
방해금지 시간에 발송 창이 닫힌 틈에 수정하는 구조다.
낮에 아무리 재시도해도 실패한다.

발송 중단은 **가역**이다 — `발송 시작` 버튼이 살아 있어 캠페인 재생성 위험은 없다.

### 기타 제약

- 워크스페이스(사업자)당 **10만 건** 발송 상한
- **비즈월렛 잔액 0이면 검수를 통과해도 발송되지 않는다** (사업자등록 게이트 안에 있음)
- 재검수 소요: 영업일 1~2일

## 스마트발송 기능성 푸시

광고성이 종료된 뒤 남은 유일한 푸시 채널이다.

| 항목 | 내용 |
|---|---|
| 심사 | 템플릿 문구 검수 |
| 전제 조건 | **사용자 사전 동의 필수** |
| 비용 | 무료 |
| 톤 | 광고 목적 문구 불가. 형식 규칙은 광고성과 같을 것으로 추정 |

> ❓ **미확인**: 광고성의 심사 규칙(제목 명사형·의문문 금지 등)이 그대로 적용되는지
> 확인되지 않았다. 첫 등록 시 반려 사유를 `case-log.md`에 기록할 것.

### 재방문 캠페인 자격 요건

**발송 시작일 전 30일간 사용자 100명 이상**이어야 한다.
미달이면 "유저 모으는 중"으로 표시되고 구조적으로 발송 불가다.

→ 유저 100명 확보가 이 채널을 여는 임계점이다.

### 어울리는 소재

**이미 제품을 써본 사람**이 대상이라 광고성과 후킹이 다르다.
광고성에서 "첫 화면에 없다"는 이유로 기각됐던 후반 콘텐츠가 여기서는 오히려 맞는다.

예: 가챠(뽑기)는 12재화를 모아야 도달하는 후반 콘텐츠라 신규 유입 광고엔 부적합했지만,
재화를 모아둔 기존 유저에게는 "뽑을 수 있어요"가 실제 경험과 일치한다.

## 결과 카드

심사가 없다. **도발·승부욕 톤의 본진이다.**

현재 티어별 문구(`src/i18n/locales/ko.ts`의 `tierMessages`)는 이 설계를 따른다:

```
낮은 등급 → 도발 ("한 판 더")
높은 등급 → 자격부여 ("친구에게 자랑")
```

재도전과 공유를 같은 카드에서 각각 다른 구간이 맡는 구조다.

| 등급 | 문구 | 역할 |
|---|---|---|
| 나무늘보급 🦥 | 고작 스테이지 N까지예요? 나무늘보도 이것보단 빨라요 | 도발 → 재도전 |
| 하마급 🦛 | 하마급에서 멈추기엔 아까워요. 한 판만 더 해봐요 | 도발 → 재도전 |
| 사슴급 🦌 | 사슴급이면 제법이에요. 친구는 여기까지 올 수 있을까요? | 전환점 |
| 여우급 🦊 | 여우급 달성! 이 정도면 친구한테 자랑해도 돼요 | 자격부여 → 공유 |
| 치타급 🐆 | 치타급 인증 🐆 이 기록을 깰 친구가 있을까요? | 자격부여 → 공유 |

**게임 내부 톤과 푸시 톤이 단절되면 안 된다.** 내부는 도발로 리텐션을 만드는데
푸시만 설명체로 나가는 것이 한때의 문제였다.

## 공유 문구

심사가 없다. 받는 사람이 **미경험자**라는 점이 결과 카드와 다르다.

현재 문구:

```
{{icon}} {{tier}} · 스테이지 {{stage}} 달성!!! 이거 이길 수 있어요?
[틀리면 끝, 동물찾기]
```

설계 의도: 소개형이 아니라 **도전장형**. 받는 사람의 승부욕을 건드려야 링크를 누른다.

### 기술 제약

- 토스가 문구 뒤에 **줄바꿈 + 딥링크를 자동으로 붙인다** (`src/platform/toss/share.ts`)
  → 문구 자체에 링크를 넣지 않는다
- 링크 생성(`Share.createLink`)이 실패하면 문구만 나간다 — 문구 단독으로도 말이 되어야 한다
- 딥링크는 `intoss://{appName}` 형식
