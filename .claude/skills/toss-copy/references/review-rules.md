# 심사 규칙

**이 규칙은 전부 반려를 맞아가며 역산한 것이다. 공식 문서에 없다.**
심사는 **소재 단위**로 자동 판정된다 — a안 통과 + b안 반려가 동시에 일어난다.
그래서 소재 2개는 A/B 실험이자 **리스크 분산**이기도 하다.

## 제목 규칙

### 🚨 순수 명사로 끝낸다

**서술성 명사(확인·도전·시작·완성·참여·신청…)는 동사로 오독되어 반려된다.**

반려 원문:
```
제목이 명사형이 아니고 동사+명령형으로 끝나 형식 규정을 위반했어요.
```

대조군이 결정적이다. 같은 회차에 제출한 두 제목:

| 제목 | 종결 | 결과 |
|---|---|---|
| 기억력 테스트 | 외래어 명사 | ✅ 통과 |
| 내 등급 확인 | 서술성 명사 | ❌ 반려 |
| 내 동물 등급 | 순수 명사 | ✅ 통과 |

사람 눈에 `확인`은 명사지만 심사 AI는 "확인하다"의 어간으로 판정한다.

**수정은 최소로 한다** — `내 등급 확인` → `내 동물 등급`은 `확인`만 덜어내고
`동물`을 넣어 자기 검증 프레임(`내`)을 유지했다.

> 💡 형식 반려가 구조적으로 불가능한 안전판: `동물 등급표`처럼 서술성이 전혀 없는 명사구

### 감정어는 통과한다 (단, 품사 형태는 지켜야)

`도전`, `두뇌휴식` 같은 감정어는 제목에서 통과한 전례가 있다.
다만 `동물찾기 도전`처럼 **앞에 명사가 붙은 복합어** 형태였다.
단독 서술성 명사 종결은 반려됐다.

### 글자 수

**7자** (공백 포함). 6~7자를 쓴다.

## 본문 규칙

### 통과 문형

```
[구체적 행동]해서 [다음 화면/결과]로 가 봐요.
```

3전 2패 끝에 이 한 문형으로 수렴했다. **평서문 · 마침표 · 서비스 내용 명시** 셋을
동시에 만족해야 한다.

### 종결 형태

| 형태 | 예 | 판정 |
|---|---|---|
| 청유형 | `~해 봐요.` `~찾아 봐요.` | ✅ 통과 |
| 평서 종결 | `~이에요.` `~나와요.` | ✅ 통과 |
| **명령형** | `~하세요.` `~해 보세요.` | ❌ **반려** |
| **의문형** | `~있나요?` `~할까요?` | ❌ **반려** |

반려 원문:
```
본문이 명령형 '-세요' 종결을 사용해서 형식 기준에 맞지 않아요.
질문형으로 끝나 형식 기준을 충족하지 않고
```

> ℹ️ 처음엔 "청유형만 된다"고 좁게 이해했으나, `~이에요` 평서 종결이 통과하면서
> **명령형·의문형이 아니면 된다**로 정정됐다.

### 🚫 쓰면 반려되는 것

| 금지 | 반려 사례 | 대안 |
|---|---|---|
| 의문문 | `몇 단계까지 갈 수 있나요` | 평서문 `~해 봐요.` |
| 명령형 `~세요` | `확인해 보세요.` | 청유형 `~해 봐요.` |
| 실패·위협 프레임 | `틀리면 끝..` | 행동·결과 서술 |
| 말줄임표 | `끝..` | 마침표 하나 |
| 소재 없는 추상 문구 | `어디까지 가는지 확인해 봐요` | `동물 짝을 맞춰 …` |
| 마침표 누락 | `~해 봐요` | `~해 봐요.` |
| 근거 없는 수치 | `상위 1%` | 코드에서 검증된 숫자만 |

반려 원문:
```
불안감을 조성하는 표현
서비스 내용을 구체적으로 알 수 없는 범용적 문구
```

### 소재를 반드시 명시한다

**장르나 감정어("두뇌", "도전")만으로는 "범용적 문구"로 반려된다.**
`동물`, `짝 맞추기` 같은 실물 단어가 본문에 있어야 한다.

### 다음 화면이 예측돼야 한다

클릭 후 무엇이 나오는지 암시하는 단어(`스테이지`, `등급`)를 넣는다.
2차 반려 사유 중 하나가 "다음 화면 예측이 어렵다"였다.

### 글자 수

**25자** (공백 포함). **19~22자를 쓴다** — 상한을 채우면 반려 후 수정할 여유가 없다.

---

## ✅ 제출 전 체크리스트

카피를 확정하기 전에 항목별로 확인한다.

### 제목
- [ ] 순수 명사로 끝나는가 (서술성 명사 ✗)
- [ ] 7자 이하인가
- [ ] 후킹이 있는가 — 이것만 읽고 누를 이유가 되는가

### 본문
- [ ] 평서문인가 (의문문 ✗)
- [ ] 명령형 `~세요`가 없는가
- [ ] 마침표로 끝나는가
- [ ] 소재 실물 단어(동물·짝 등)가 있는가
- [ ] 다음 화면이 예측되는가
- [ ] 위협·말줄임표가 없는가
- [ ] 19~22자인가 (25자 상한을 채우지 않았는가)

### 전체
- [ ] 제목과 본문이 같은 장면을 가리키는가 (one message)
- [ ] 숫자·단정 표현의 근거를 **해당 함수를 직접 열어** 확인했는가
- [ ] 소재 2개의 욕구 축이 실제로 다른가
- [ ] 소리 내어 읽어도 어색하지 않은가
- [ ] 예비안을 준비했는가 (반려 전제)

### ⚙️ 기계로 확인할 것

자수는 눈으로 세면 틀린다. 실제로 21자로 알았던 카피가 19자, 22자로 알았던 카피가
23자였다. 아래를 돌려 확인한다.

```bash
python3 -c "
copies = [
    ('a안', '제목', '본문'),
    ('b안', '제목', '본문'),
]
for tag, t, b in copies:
    print(f'{tag} 제목 {len(t)}자 {\"OK\" if len(t)<=7 else \"초과\"} | 본문 {len(b)}자 {\"OK\" if 19<=len(b)<=22 else \"권장벗어남\"} | 마침표 {b.endswith(chr(46))} 물음표 {chr(63) in b} 말줄임표 {\"..\" in b}')
"
```

**심사 통과는 사실 검증이 아니다.** 심사 AI는 형식만 본다 —
거짓 사실이 담긴 카피도 통과한다(`case-log.md` a안 사실 오류 사례 참조).
숫자가 코드의 다른 값과 비슷하면 반드시 혼동하므로, 기억에 의존하지 말고 함수를 연다.

## 반려 루프 손절 기준

**같은 소재가 2회 반려되면 그 안은 버리고 통과한 소재로만 발송한다.**

발송 기간은 반려-수정 사이클마다 줄어든다(재검수 영업일 1~2일).
A/B 비교 데이터보다 **실제 발송이 나가는 것**이 우선이다.

카피는 처음부터 **3안 이상 준비한다.** 실험 비용이 아니라 **재시도 비용** 때문이다.

---

## 새 반려 사유를 만났을 때

1. 반려 원문을 그대로 기록한다
2. 같은 회차에 통과한 소재가 있으면 **둘의 차이가 곧 규칙**이다
3. 개별 문구가 아니라 **"무엇이 금지인가"를 규칙으로 추출**해 이 파일에 추가한다
4. `case-log.md`에 실물 사례를 남긴다

공식 문서가 심사 AI의 판정 기준을 커버하지 못하므로 이 파일이 유일한 기록이다.
