# 게임 등급분류(GRAC) 처리 매뉴얼 — Google Play Console 활용

> 이 문서는 앱인토스 미니앱 출시 시 필요한 "게임 등급분류"를 무료로, 실제 스토어 공개 없이 받는 절차를 정리한 것이다.
> `틀리면 끝, 매칭왕` 출시 과정에서 처음 밟은 절차를 기록했고, **앞으로 낼 다른 미니앱에도 동일하게 재사용**한다.

> 📌 **스크린샷 넣는 법**: 아래 `![...]` 이미지 자리마다 파일명이 지정돼 있다. `docs/manuals/assets/game-rating/` 폴더에 그 파일명 그대로 이미지를 저장하면 자동으로 연결된다. 폴더는 이미 만들어뒀다.

## 왜 필요한가

![앱인토스 콘솔 — 게임 등급분류 탭, 스토어 링크 입력 화면](assets/game-rating/01-apps-in-toss-rating-tab.png)

한국 게임산업진흥법상 모든 게임은 등급분류를 받아야 출시할 수 있다. 앱인토스 콘솔의 "앱 정보 등록하기 → 게임 등급분류" 단계에서:

- 이미 앱스토어/플레이스토어에 출시된 게임 → **스토어 링크**만 제출하면 됨
- 아직 어디에도 출시 안 한 게임(미니앱 첫 출시 등) → **자체등급분류 게임물 정보**를 직접 입력해야 함

자체등급분류 정보(등록자명, 자체등급분류사업자명, 등급분류일자, 등급분류번호)는 콘솔에서 새로 만드는 게 아니라, **GRAC(게임물관리위원회)이 지정한 자체등급분류사업자를 통해 먼저 등급을 받은 뒤, GRAC 사이트에서 조회해서 옮겨 적는 것**이다.

## 왜 Google Play Console인가

GRAC 지정 자체등급분류사업자 중 구글 플레이가 제일 저렴하고 접근성이 좋다.

| 사업자 | 비용 | 비고 |
|---|---|---|
| 구글 플레이 콘솔 | 최초 1회 $25 (평생) | 이미 계정 있으면 $0 — 추천 |
| 원스토어 | 보통 무료 | 계정 없으면 이쪽도 고려 |
| 애플 App Store Connect | 연 $99 | 이 용도로는 비추천 |

**핵심: 실제로 스토어에 공개(출시)할 필요가 없다.** Play Console에 앱을 만들고 콘텐츠 등급 설문만 제출하면 등급이 나온다. 앱을 계속 비공개/미출시 상태로 둬도 무방하다.

## 절차

### 1. Play Console에 앱 생성

![Play Console — 앱 만들기 폼](assets/game-rating/02-play-console-create-app.png)

Play Console → **앱 만들기** → 아래 값 입력:

| 필드 | 입력값 |
|---|---|
| 앱 이름 | 실제 게임 이름 그대로 (GRAC 조회 시 이 이름으로 검색하게 됨) |
| 패키지 이름 | `com.{도메인}.{앱영문명}` 형식. 실제 배포 안 할 거라 형식만 맞으면 아무 값이나 가능 |
| 기본 언어 | **한국어 - 대한민국**으로 변경 (기본값 영어에서 꼭 바꿀 것) |
| 앱 또는 게임 | **게임** |
| 유료 또는 무료 | **무료** |

> ⚠️ 이 앱 항목은 **절대 삭제하지 말 것** — GRAC 등급분류 기록이 여기 연결된다.

### 2. "앱 콘텐츠" 메뉴 찾기

![Play Console — 앱 콘텐츠 페이지, 좌측 메뉴 경로](assets/game-rating/04-app-content-menu.png)

위치가 계정/시기에 따라 조금씩 다르게 배치되는데, 이번엔 여기 있었다:

```
모니터링 및 개선 → 정책 및 프로그램 → 앱 콘텐츠
```

("게시 개요"에도 체크리스트 형태로 뜨는 경우가 있으니, 위 경로에 없으면 그쪽도 확인.)

### 3. "콘텐츠 등급" 선언

앱 콘텐츠 페이지에 뜨는 여러 선언 항목(개인정보처리방침, 광고, 데이터 보안 등) 중 **"콘텐츠 등급" 하나만** 지금 단계에선 필요하다. 나머지는 실제 스토어 공개용이라 무시해도 됨.

"콘텐츠 등급" 카드 → **선언 시작**:

1. **이메일 주소**: 이 게임 전용으로 만들어둔 그룹 메일 사용 (예: `matchingking@freefromjob.kr`)
2. **카테고리**: 반드시 **"게임(Game)"** 선택
3. 질문지 답변 — 실제 게임 내용 기준, 캐주얼 매칭 게임(폭력·성적 콘텐츠·현금성 도박 없음) 기준 답변 예시:
   - 폭력적 묘사: 없음
   - 성적 콘텐츠: 없음
   - 도박/현금성 요소: 없음 (인게임 재화 뽑기는 현금 도박 아님)
   - 욕설/부적절한 언어: 없음
   - 사용자 간 상호작용/채팅: 없음
   - 광고 포함: 예 (인앱 광고 있으면)
   - 인앱 구매: 실제 결제 기능 있으면 예, 없으면 아니오
4. 결과 미리보기 확인 (국가별 등급이 쭉 나옴 — 한국/GRAC 항목 확인) → **저장**

![Play Console — 콘텐츠 등급 결과 미리보기 (국가별 등급)](assets/game-rating/05-content-rating-preview.png)

> **설문만으로 통과되는 게 맞다.** IARC(구글이 쓰는 등급 시스템)는 스크린샷·영상 제출 없이 질문 응답만으로 즉시 등급을 산정하는 자기신고 방식이다. 단, 답변이 실제 게임 내용과 다르면 나중에 등급이 취소될 수 있으니 정직하게 답변할 것.

### 4. 결과 확인 & 대기

![Play Console — 콘텐츠 등급 최종 화면 (IARC 상태: 완료됨)](assets/game-rating/06-content-rating-complete.png)

저장 직후엔 "IARC 상태: 완료됨"으로 뜨지만, **"IARC 인증 ID"는 바로 채워지지 않을 수 있다** (반영에 며칠 소요). 하루 이틀 뒤 다시 확인.

### 5. GRAC에서 조회

며칠 뒤, [게임물관리위원회](https://www.grac.or.kr) **"자체등급분류 게임물 조회"** 메뉴에서 게임 이름 또는 패키지명으로 검색 → 아래 4개 값 확보:

- 등록자명
- 자체등급분류사업자명 (예: 구글)
- 등급분류일자
- 등급분류번호

### 6. 앱인토스 콘솔에 입력

"앱 정보 등록하기 → 게임 등급분류" → 아래 세 섹션을 채운다.

#### 6-1. 등록 정보 섹션 (GRAC과 무관, Play Console 계정 정보 그대로)

이 섹션은 GRAC 조회 결과가 아니라 **Google Play Console 개발자 계정에 등록된 정보**를 그대로 옮기는 곳이다.

Play Console → 좌측 "개발자 계정" → "내 정보"에 보면 이름이 두 개 나온다. **반드시 "법적 이름 및 주소" 쪽을 쓸 것** — "개발자 이름"(스토어에 노출되는 퍼블릭 브랜드명, 영문일 수 있음)은 여기와 무관하다.

| Toss 콘솔 필드 | 값의 출처 |
|---|---|
| 앱마켓 게임등록자명(사업자명) | Play Console "법적 이름 및 주소"의 이름 (개인 계정이면 본인 이름) |
| 대표자명 | 위와 동일 |
| 주소 | Play Console "법적 이름 및 주소"의 주소 (이사해서 실거주지와 다르면, **Play Console에 등록된 주소를 그대로** 쓸 것 — 실거주지 일치 여부가 아니라 "앱마켓 등록 정보와의 일치"가 목적) |
| 전자메일주소 | 게임 전용 그룹 이메일 |
| 전화번호 | Play Console 계정 등록 전화번호 |

#### 6-2. 자체등급분류 게임물 정보 섹션

5단계에서 GRAC 조회로 얻은 4개 값(등록자명/자체등급분류사업자명/등급분류일자/등급분류번호)을 입력.

> ⚠️ **"게임물제작업자의 신고번호 또는 등록번호" 필드 주의**: 이건 GRAC 등급분류와는 별개로, 게임산업진흥법상 지자체(구청 등)에 하는 게임 제작업/배급업 신고 번호다. **법상 "개인이 청소년이용불가가 아닌 게임을 제작·배급하는 경우"는 이 신고 의무가 면제되는 조항이 있어** 개인+전체이용가 조건이면 해당 없을 가능성이 높지만, 이 부분은 법 해석이 걸린 문제라 **단정하지 말고** 필수 입력이 막히면 앱인토스 채널톡으로 직접 확인할 것.

#### 6-3. "게임 주요화면" 섹션 — 실제 스크린샷 필요

"등급분류를 받은 게임이 출시하려는 게임과 화면이 동일해야 해요"라는 안내가 있다. **자체등급분류 게임물 화면 / 앱인토스 게임물 화면 두 슬롯에 같은 파일을 넣는 게 정상**이다(등급 받을 때와 지금이 안 바뀌었다는 증명이라서).

단, 반드시 **실제 앱을 캡처한 진짜 스크린샷**을 써야 한다 — 브랜드 톤을 살린 재현/목업 이미지는 이 자리에 부적합하다 (마케팅용 스토어 스크린샷과는 요구사항이 다름).

**실제 캡처가 막힐 때 쓴 방법** (Claude Browser 프리뷰 도구가 스크린샷을 파일로 저장 못 해주는 경우):

1. `preview_start`로 dev 서버 실행 → 원하는 화면까지 진행
2. `javascript_tool`로 `html2canvas` CDN(`https://cdn.jsdelivr.net/npm/html2canvas@1.4.1/dist/html2canvas.min.js`) 동적 로드
3. `html2canvas(document.body, {backgroundColor: '#FFF8EC', width, height, windowWidth, windowHeight})` 실행 → `canvas.toDataURL('image/png')`로 실제 DOM을 그대로 이미지화
4. 결과가 너무 커서 도구 응답이 잘리면, 하네스가 자동으로 저장해주는 로컬 텍스트 파일 경로에서 base64 부분만 잘라 `base64.b64decode`로 실제 PNG 파일 복원
5. `sips -z {height} {width}` 로 비율 유지 축소 → `sips -p {targetH} {targetW} --padColor {배경색hex}` 로 요구 캔버스 크기(예: 636×1048)에 레터박스 패딩

이 방식으로 실제 게임플레이 화면과 스테이지 클리어 다이얼로그를 정확한 픽셀 사이즈로 캡처했다.

## 수익화(인앱 광고) 관련 별도 이슈

게임 등급분류와는 무관하지만 같은 흐름에서 확인한 사실 — **인앱 광고 등 수익화 기능은 사업자 등록이 필수**다 (개인 무사업자는 정산 자체가 불가). Play Console 계정을 사업자로 바꿀 필요는 없다 — 이건 앱인토스 콘솔 워크스페이스에 별도로 등록하는 절차라 완전히 독립적이다. 자세한 건 [사업자등록 체크리스트] 참고(추후 이 저장소에도 별도 문서화 예정).
