# 게임 등급분류(GRAC) 처리 매뉴얼

> `틀리면 끝, 매칭왕` 출시 과정에서 실제로 밟은 절차와 시행착오를 기록했다. **앱인토스에만 출시하고 다른 스토어엔 안 낼 계획이면, 반드시 "GRAC 직접 신청" 섹션부터 읽을 것** — Google Play 자체등급분류 경로로 먼저 시도했다가 막혀서 뒤늦게 방향을 바꿨다(아래 "시행착오" 참고).

> 📌 **스크린샷 넣는 법**: 아래 `![...]` 이미지 자리마다 파일명이 지정돼 있다. `docs/manuals/assets/game-rating/` 폴더에 그 파일명 그대로 이미지를 저장하면 자동으로 연결된다.

## TL;DR — 앱인토스 전용 출시라면

> **"게임 등급은 두 가지 방법으로 받을 수 있어요. 하나는 게임물관리위원회(GRAC)를 통해 직접 신청하는 방법, 또 하나는 앱스토어·구글플레이 등 주요 스토어의 연령 등급 설문을 통해 자동으로 등급을 받는 방법이에요. ... 단, 앱인토스에서는 스토어에 실제로 등록된 게임의 URL을 통해 등급을 확인하기 때문에 출시 절차까지 모두 완료해야 해요."**
> — [앱인토스 공식 블로그: 게임 출시 전, 꼭 알아야 하는 '게임 등급분류'](https://toss.im/apps-in-toss/blog/game_rating_classification) (원본 HTML 직접 확인, 2026-08-15 검증)

즉 **구글 플레이/앱스토어의 "자동 심의(자체등급분류)"는 그 스토어에 실제로 출시(공개)한 게임에만 쓸 수 있다.** 앱인토스에만 낼 거면 이 지름길을 못 쓰고, **① GRAC에 직접 신청**하거나 **② 실제로 다른 오픈마켓에도 출시**해야 한다. 대부분의 솔로 개발자에겐 ①이 맞다.

## ① GRAC 직접 신청 (앱인토스 전용 출시 시 정석 경로)

### 준비물
- **사업자 등록 (사실상 필수)** — GRAC 회원가입 페이지 기준(2026-08-15 확인): **업체회원** = "사업자 또는 사업체를 대표하는 신청인(개인사업자·법인 모두 포함)", **개인회원** = "사업자가 아닌 신청인(**PC 게임물·오픈마켓용 모바일게임물로 한정**)". 우리 케이스(스토어명 "기타-앱인토스")는 오픈마켓용이 아니라서 개인회원 자격 자체가 안 된다 — 사업자 등록 후 업체회원으로 신청해야 함.
- **게임물내용설명서**
- **실행 가능한 게임물** — 정확한 제출 형식(웹 링크? 빌드 파일?)이 [앱인토스 개발자 커뮤니티에도 같은 질문이 미답변으로 남아있음](https://techchat-apps-in-toss.toss.im/t/grac/4500). 채널톡/GRAC 고객센터 문의 필요.
- **게임물 진행과정 동영상** — 선정성·폭력성·약물및범죄·언어의 부적절성·사행성 각 항목이 노출되는 장면을 포함해야 함(심의 항목과 영상 내용이 매칭돼야 함)
- **(사업자인 경우) 게임물제작업자등록증 또는 게임물배급업자등록증**
- **심의 수수료** — 아래 계산 참고

### 신청 절차 (GRAC 사이트, 원문 그대로 정리)

출처: [앱인토스 블로그 원문 HTML 직접 확인](https://toss.im/apps-in-toss/blog/game_rating_classification)

1. [게임물관리위원회(GRAC)](https://www.grac.or.kr/)에서 로그인 (개인 사업자 신청인은 업체 회원으로)
2. 상단 메뉴 [등급분류신청] → **[오픈마켓/등급분류 신청]** 선택
3. 신청인 정보 확인 + 게임정보·원작정보 입력 — **플랫폼: 모바일 게임**, **스토어명: '기타-앱인토스'**
4. 구비서류 확인 → 다음 단계 (청소년이용가 게임은 간소화 신청 가능)
5. 담당자 정보 + 게임물 개요 작성
6. 게임물 상세정보 입력 — **서비스 방식(네트워크 접속 방식): 인터넷 접속**
7. 등급분류 내용정보 작성 (선정성·폭력성·약물및범죄·언어의부적절성·사행성 체크) — 이 항목들이 8번의 심의용 영상에도 반드시 포함돼야 함
8. 첨부문서 업로드 (사업자인 경우 게임물제작업자등록증/배급업자등록증, 게임물내용설명서, 실행 가능한 게임물, 진행과정 동영상)
9. 심의 수수료 계산 → 입금 → 입금증 업로드
10. 철회/환불 안내 동의 → [신청 완료]

**소요 기간: 약 10~15일.** 완료되면 **'등급분류증명서'(PDF)**가 발급되고, 이게 국내 모든 유통·운영 채널에서 공식 근거로 인정된다.

### 심의 수수료

계산기: [GRAC 모의수수료 계산](https://www.grac.or.kr/SupplementaryService/SimulatedCaculation.aspx)

공식: `심의수수료 = 플랫폼별 기초가액 × 이용형태계수 × 장르별계수 × 한글화계수`

| 항목 | 매칭킹 기준 선택값 | 이유 |
|---|---|---|
| 신청구분 | **오픈마켓** | 앱인토스 케이스는 [오픈마켓/등급분류 신청] 메뉴 사용 — ⚠️ 이 구분을 고르면 기초가액에서 "모바일게임" 옵션 자체가 사라지고 "기타(용량별)"만 남는다 |
| 기초가액 | **기타(10MB미만) 30,000원** | `npm run build` 결과물(`matchingking.ait`) 실측 4,450,823 bytes(≈4.24MB) — 10MB 미만 확정 (2026-08-15 측정) |
| 이용형태계수 | **NON 네트워크(1.0)** | 정의: "네트워크=대전을 통해 진행" vs "NON네트워크=부가기능(랭킹 등록 등)만 네트워크 이용". 매칭킹은 실시간 대전 없이 리더보드(랭킹)만 씀 → NON네트워크 |
| 장르별계수 | **3군(1.0)** | 정의: "3군=보드(퍼즐, 퀴즈, 바둑 등)". 카드 매칭/기억력 퍼즐 게임 |
| 한글화계수 | **한글(1.0)** | 한국어 게임 |

**결과 (2026-08-15 실측·확정):**
- **업체회원(사업자) 신청: 30,000원 ← 매칭킹은 이걸로 확정**
- ~~개인회원 신청: 15,000원~~ — GRAC 회원가입 페이지에서 확인한 결과 **해당 없음**. 정의를 보면:
  - 업체회원: "사업자 또는 사업체를 대표하는 신청인" **(개인사업자, 법인 모두 포함)**
  - 개인회원: "사업자가 아닌 신청인" **(PC 게임물, 오픈마켓용 모바일게임물로 한정)**
  
  매칭킹은 스토어명이 "기타-앱인토스"라 오픈마켓용이 아니고, 게다가 사업자 등록도 어차피 진행할 예정이라 **업체회원 30,000원이 확정 금액**이다. (2026-08-15, GRAC 회원가입 페이지 직접 확인)

### 신청 완료 후 앱인토스 콘솔 입력

"앱 정보 등록하기 → 게임 등급분류" 드롭다운을 **"게임물 등급분류증명서"**로 변경 → 발급받은 PDF 첨부.

## ② 오픈마켓(구글 플레이 등)에도 실제로 출시하는 경우

이 프로젝트(매칭킹)엔 해당 없지만, 나중에 다른 미니앱을 오픈마켓에도 동시 출시할 계획이면 이 경로가 더 간단할 수 있다 (무료, 설문만으로 즉시 등급 산정). **단, 반드시 그 스토어에 실제로 출시(공개)까지 완료해야 한다** — 콘텐츠 등급 설문만 작성하고 미출시 상태로 두면 GRAC 조회에도 안 올라간다 (아래 "시행착오" 참고).

- Apple App Store 개발자 가입: $99/년
- Google Play Console: $25(최초 1회)
- ONEstore / MS Store: 무료

절차: 각 스토어 개발자 계정 생성 → 앱 콘텐츠에서 콘텐츠 등급(IARC) 설문 작성 → **실제 출시(스토어 공개) 완료** → GRAC "자체등급분류 게임물 조회"에서 검색 → 등록자명/자체등급분류사업자명/등급분류일자/등급분류번호를 앱인토스 콘솔 "스토어 링크" 옵션에 입력.

## ⚠️ 시행착오 기록 — Google Play Console로 먼저 시도했다가 막힌 과정

처음엔 "실제 공개 없이 Play Console에서 콘텐츠 등급 설문만 완료하면 된다"고 판단하고 진행했다. 결과:

1. Play Console에 앱 생성(비공개 상태 유지) → 콘텐츠 등급 설문 완료 → 국가별 등급(한국 GRAC 포함 "전체이용가")이 화면에 표시됨
2. 하지만 12시간 이상 지나도 GRAC "자체등급분류 게임물 조회"에서 검색 자체가 안 됨
3. 원인을 다시 조사한 결과, 위 TL;DR 인용문대로 **"오픈마켓에 실제로 출시된 게임 URL"이 있어야 GRAC 자체등급분류 DB에 등록된다**는 걸 확인 — 비공개 draft 상태로는 콘텐츠 등급 자체(IARC 국가별 등급 화면 표시)는 되지만 GRAC 유통 통보까지는 안 감
4. 결론: 앱인토스에만 낼 거면 애초에 이 경로 자체가 안 맞았음. **안드로이드 네이티브 앱을 새로 만들 필요는 없다** — 그냥 GRAC에 직접 신청하면 된다.

이 Play Console 앱 항목 자체는 지워도 무해하지만, 나중에 다른 미니앱을 오픈마켓에도 낼 계획이 있다면 재사용 가능하니 남겨둬도 된다.

## "게임 주요화면" 스크린샷 준비 (양쪽 경로 공통)

앱인토스 콘솔에 업로드하는 게임 화면은 **실제 앱을 캡처한 진짜 스크린샷**이어야 한다 (재현/목업 이미지 부적합).

**실제 캡처가 막힐 때 쓴 방법** (Claude Browser 프리뷰가 스크린샷을 파일로 저장 못 해주는 경우):

1. `preview_start`로 dev 서버 실행 → 원하는 화면까지 진행
2. `javascript_tool`로 `html2canvas` CDN(`https://cdn.jsdelivr.net/npm/html2canvas@1.4.1/dist/html2canvas.min.js`) 동적 로드
3. `html2canvas(document.body, {backgroundColor, width, height, windowWidth, windowHeight})` → `canvas.toDataURL('image/png')`로 실제 DOM을 그대로 이미지화
4. 결과가 너무 커서 도구 응답이 잘리면, 하네스가 자동 저장하는 로컬 텍스트 파일에서 base64 부분만 잘라 `base64.b64decode`로 실제 PNG 파일 복원
5. `sips -z {height} {width}`로 비율 유지 축소 → `sips -p {targetH} {targetW} --padColor {배경색hex}`로 요구 캔버스 크기(예: 636×1048)에 레터박스 패딩

## 다음 미니앱에 재사용할 때 체크리스트

- [ ] 이 미니앱을 **앱인토스에만** 낼 건지, 다른 오픈마켓에도 낼 건지 먼저 결정 — 경로가 완전히 갈림
- [ ] **앱인토스 전용**이면 → 사업자 등록 먼저 → GRAC "오픈마켓/등급분류 신청"(스토어명 "기타-앱인토스") → 수수료 계산·납부 → 10~15일 대기 → 등급분류증명서 PDF를 콘솔에 첨부
- [ ] **오픈마켓 동시 출시**면 → 해당 스토어에 실제 출시 완료 → GRAC 조회 → 스토어 URL + 조회 정보를 콘솔에 입력
- [ ] `npm run build`로 최신 `.ait` 용량 실측 후 수수료 구간 확정
- [ ] 게임 주요화면 2장은 반드시 실제 캡처로 준비 (html2canvas 방법 재사용)
- [ ] "실행 가능한 게임물" 제출 형식은 매번 채널톡/GRAC에 재확인 (공식 문서에 명확한 답 없음)
