> **"게임 등급은 두 가지 방법으로 받을 수 있어요. 하나는 게임물관리위원회(GRAC)를 통해 직접 신청하는 방법, 또 하나는 앱스토어·구글플레이 등 주요 스토어의 연령 등급 설문을 통해 자동으로 등급을 받는 방법이에요. ... 단, 앱인토스에서는 스토어에 실제로 등록된 게임의 URL을 통해 등급을 확인하기 때문에 출시 절차까지 모두 완료해야 해요."**
> — [앱인토스 공식 블로그: 게임 출시 전, 꼭 알아야 하는 '게임 등급분류'](https://toss.im/apps-in-toss/blog/game_rating_classification) (원본 HTML 직접 확인, 2026-08-15 검증)

못 쓴다"는 제약으로만 읽었는데, 뒤집어 보면 **"오픈마켓에 실제로 내기만 하면 쓸 수 있다"**
는 뜻이다. Play Console 등록비는 **$25 최초 1회**뿐이고 이미 지불한 상태였다.

## ① 0원 경로 — Play 스토어 선(先)출시 (매칭킹이 실제로 쓴 경로)

### 왜 이게 되나

Google Play는 **자체등급분류사업자**다. Play에 게임을 실제로 공개하면 IARC 설문 결과가
GRAC 자체등급분류 DB에 유통 통보되고, 앱인토스 콘솔은 그 DB를 조회해 등급을 확인한다.
GRAC에 직접 신청할 이유가 없어진다.

### 절차

1. **Play Console에 게임 등록 → 콘텐츠 등급(IARC) 설문 작성**
2. **⚠️ 실제로 출시(스토어 공개)까지 완료한다** — 이 단계가 전부다. 비공개/내부테스트
   상태로는 GRAC DB에 안 올라간다(아래 ④ 시행착오 참고)
3. Play 심사 통과·공개 확인
4. **GRAC "자체등급분류 게임물 조회"** 에서 게임명으로 검색 → 등록자명 · 자체등급분류사업자명 ·
   등급분류일자 · 등급분류번호 확인
5. 앱인토스 콘솔 "앱 정보 등록하기 → 게임 등급분류" 에서 **"스토어 링크"** 옵션 선택 →
   4번의 조회 정보와 스토어 URL 입력

### 비용

| 항목 | 금액 |
|---|---|
| Google Play Console 등록 | **$25 (최초 1회, 계정당)** |
| GRAC 심의 수수료 | **0원** |
| 사업자등록 | **불필요** |
| **합계(계정 보유 시)** | **0원** |

참고로 다른 오픈마켓도 자체등급분류사업자다 — Apple App Store($99/년), ONE store(무료),
MS Store(무료). Play가 아니어도 되지만, 무료이고 심사가 빠른 쪽을 고르면 된다.

### 매칭킹 실제 소요

Play 심사에서 **등록정보 불일치로 한 번 반려**됐고(런처 라벨 ↔ 스토어 등록정보), 아이콘
교체와 재제출을 거쳐 통과했다. 상세는 [[2026-09-02_play-심사거부-등록정보불일치-대응]] ·
[[2026-08-28_play-store-출시-트러블슈팅]] 참고. **Play 심사가 실질 병목**이지 등급분류는
아니었다.

## ② GRAC 직접 신청 — 오픈마켓에 안 낼 때만

**어떤 오픈마켓에도 내지 않고 앱인토스에만 출시할 때**의 경로다. 매칭킹은 쓰지 않았다.
이 경우에만 아래를 따른다.

### 준비물

- **사업자 등록 (사실상 필수)** — GRAC 회원가입 페이지 기준(2026-08-15 확인): **업체회원** = "사업자 또는 사업체를 대표하는 신청인(개인사업자·법인 모두 포함)", **개인회원** = "사업자가 아닌 신청인(**PC 게임물·오픈마켓용 모바일게임물로 한정**)". 스토어명 "기타-앱인토스"는 오픈마켓용이 아니라서 개인회원 자격이 안 된다 — 사업자 등록 후 업체회원으로 신청해야 함.
- **게임물내용설명서**
- **실행 가능한 게임물** — 정확한 제출 형식(웹 링크? 빌드 파일?)이 [앱인토스 개발자 커뮤니티에도 미답변으로 남아있음](https://techchat-apps-in-toss.toss.im/t/grac/4500). 채널톡/GRAC 고객센터 문의 필요.
- **게임물 진행과정 동영상** — 선정성·폭력성·약물및범죄·언어의 부적절성·사행성 각 항목이 노출되는 장면을 포함해야 함
- **(사업자인 경우) 게임물제작업자등록증 또는 게임물배급업자등록증**
- **심의 수수료**

### 신청 절차

출처: [앱인토스 블로그 원문 HTML 직접 확인](https://toss.im/apps-in-toss/blog/game_rating_classification)

1. [게임물관리위원회(GRAC)](https://www.grac.or.kr/)에서 로그인 (개인 사업자 신청인은 업체 회원으로)
2. 상단 메뉴 [등급분류신청] → **[오픈마켓/등급분류 신청]** 선택
3. 신청인 정보 확인 + 게임정보·원작정보 입력 — **플랫폼: 모바일 게임**, **스토어명: '기타-앱인토스'**
4. 구비서류 확인 → 다음 단계 (청소년이용가 게임은 간소화 신청 가능)
5. 담당자 정보 + 게임물 개요 작성
6. 게임물 상세정보 입력 — **서비스 방식(네트워크 접속 방식): 인터넷 접속**
7. 등급분류 내용정보 작성 (선정성·폭력성·약물및범죄·언어의부적절성·사행성 체크) — 이 항목들이 8번의 심의용 영상에도 반드시 포함돼야 함
8. 첨부문서 업로드
9. 심의 수수료 계산 → 입금 → 입금증 업로드
10. 철회/환불 안내 동의 → [신청 완료]

**소요 기간: 약 10~15일.** 완료되면 **'등급분류증명서'(PDF)** 가 발급된다.

### 심의 수수료 (매칭킹 기준으로 계산해뒀던 값)

계산기: [GRAC 모의수수료 계산](https://www.grac.or.kr/SupplementaryService/SimulatedCaculation.aspx)

공식: `심의수수료 = 플랫폼별 기초가액 × 이용형태계수 × 장르별계수 × 한글화계수`

| 항목 | 매칭킹 기준 선택값 | 이유 |
|---|---|---|
| 신청구분 | **오픈마켓** | [오픈마켓/등급분류 신청] 메뉴 사용 — ⚠️ 이 구분을 고르면 기초가액에서 "모바일게임" 옵션이 사라지고 "기타(용량별)"만 남는다 |
| 기초가액 | **기타(10MB미만) 30,000원** | `.ait` 실측 4,450,823 bytes(≈4.24MB) — 10MB 미만 (2026-08-15 측정) |
| 이용형태계수 | **NON 네트워크(1.0)** | "네트워크=대전으로 진행" vs "NON네트워크=부가기능(랭킹 등)만 네트워크". 매칭킹은 실시간 대전 없이 리더보드만 씀 |
| 장르별계수 | **3군(1.0)** | "3군=보드(퍼즐, 퀴즈, 바둑 등)" |
| 한글화계수 | **한글(1.0)** | 한국어 게임 |

**결과: 업체회원 30,000원.** 개인회원 15,000원은 해당 없음(위 자격 정의 참고).

> ℹ️ SDK 3.x 이후 `.ait` 용량이 **4.3MB → 739KB**로 줄었다(React Native 셸 번들이 서버로
> 이동). 10MB 미만 구간은 그대로다.

### 신청 완료 후 앱인토스 콘솔 입력

"앱 정보 등록하기 → 게임 등급분류" 드롭다운을 **"게임물 등급분류증명서"** 로 변경 →
발급받은 PDF 첨부.

## ③ "게임 주요화면" 스크린샷 준비 (양쪽 경로 공통)

앱인토스 콘솔에 업로드하는 게임 화면은 **실제 앱을 캡처한 진짜 스크린샷**이어야 한다
(재현/목업 이미지 부적합).

**실기기 캡처가 막힐 때 쓴 방법** (Claude Browser 프리뷰가 스크린샷을 파일로 저장 못 하는 경우):

1. `preview_start`로 dev 서버 실행 → 원하는 화면까지 진행
2. `javascript_tool`로 `html2canvas` CDN(`https://cdn.jsdelivr.net/npm/html2canvas@1.4.1/dist/html2canvas.min.js`) 동적 로드
3. `html2canvas(document.body, {backgroundColor, width, height, windowWidth, windowHeight})` → `canvas.toDataURL('image/png')`
4. 결과가 커서 도구 응답이 잘리면, 하네스가 저장하는 로컬 텍스트 파일에서 base64만 잘라 `base64.b64decode`로 PNG 복원
5. `sips -z {h} {w}`로 비율 유지 축소 → `sips -p {targetH} {targetW} --padColor {hex}`로 요구 캔버스 크기에 레터박스 패딩

> ℹ️ SDK 3.x부터 샌드박스 앱 없이 **로컬 브라우저 + AIT Devtools**로 화면을 띄울 수 있어
> 이 캡처가 훨씬 쉬워졌다. [[2026-07-23_샌드박스-테스트-빌드-배포-가이드]] 의 3.x 절 참고.

### 콘솔 이미지 규격 (2026-09-09 확인)

| 항목 | 규격 |
|---|---|
| 앱 로고 | **600×600 PNG**, 배경 필수(투명 불가), 둥근 모서리 불가, 다크모드 고려 |
| 썸네일(게임) | 1932×828 PNG |
| 스크린샷(세로) | 636×1048 PNG, **최소 3장** |
| 스크린샷(가로) | 1504×741 PNG, 최소 1장 |

⚠️ Play 스토어 규격(아이콘 512×512, 스크린샷 1080×1920)과 **다르다.** 매칭킹은 Play용
512×512를 600×600으로 리사이즈하고 알파 채널을 제거해서 썼다
(`store-assets/toss/app-icon-600x600.png`).

## ④ 이력 — 왜 08-15에는 "GRAC 직접 신청"이라고 판단했나

> 아래는 **개정 전 판단의 근거**다. 결론은 뒤집혔지만 삭제하지 않는다 — 같은 함정을
> 다시 밟지 않으려면 왜 그렇게 읽었는지가 남아야 한다.

### 시행착오 기록 — Play Console로 시도했다가 막힌 과정 (2026-08-15)

처음엔 "실제 공개 없이 Play Console에서 콘텐츠 등급 설문만 완료하면 된다"고 판단하고 진행했다.

1. Play Console에 앱 생성(**비공개 상태 유지**) → 콘텐츠 등급 설문 완료 → 국가별 등급(한국 GRAC 포함 "전체이용가")이 화면에 표시됨
2. 하지만 12시간 이상 지나도 GRAC "자체등급분류 게임물 조회"에서 검색이 안 됨
3. 원인: **"오픈마켓에 실제로 출시된 게임 URL"이 있어야 GRAC 자체등급분류 DB에 등록된다.**
   비공개 draft 상태로는 IARC 국가별 등급 화면 표시까지는 되지만 GRAC 유통 통보까지는 안 감
4. 당시 결론: "앱인토스에만 낼 거면 이 경로가 안 맞다 → GRAC 직접 신청"

**이 3번까지의 관찰은 지금도 사실이다. 틀린 건 4번이다.** "앱인토스에만 낸다"를 고정
제약으로 두고 경로를 고른 것인데, 실제로는 **그 제약 자체를 푸는 게 압도적으로 쌌다.**
Play 출시는 이미 별도 트랙에서 진행 중이었고([[2026-08-18_play스토어-게임-poc-트랙-개설]]),
그게 등급분류까지 해결해 줄 거라는 연결을 08-15에는 못 봤다.

### 교훈

**"A 경로가 막혔다"에서 곧바로 "B 경로로 간다"로 가지 말 것.** A의 전제 조건을 충족시키는
비용과 B의 비용을 비교해야 한다. 여기서는 A의 전제(오픈마켓 출시)가 이미 다른 트랙에서
진행 중이었는데도, 그걸 "지금 없는 것"으로 취급해 30,000원 + 10~15일 + 사업자등록을
받아들이려 했다.

### 매칭킹 최종 처리 기록

| 항목 | 값 |
|---|---|
| **선택한 경로** | **① Play 자체등급분류 (0원)** |
| 등급분류 상태 | ✅ **완료** — Play 자체등급분류로 앱인토스 콘솔 등록 통과 (2026-09-08) |
| 앱인토스 출시 | ✅ **완료** (2026-09-09) — 등급분류는 출시 경로에서 병목이 아니었다 |
| GRAC 직접 신청 | **미사용** — 30,000원 미지출 |
| 사업자등록 | **미진행** — 게임 출시에 불필요했음 |
| 최신 빌드 용량 | 739KB (SDK 3.x, 2026-09-09) / 이전 4.24MB (2.x) |

## 다음 미니앱에 재사용할 때 체크리스트

- [ ] **게임이면 Play(또는 다른 오픈마켓)에 먼저 낸다.** 앱인토스 전용으로 갈 이유가 없다 —
      등급분류가 0원이 되고, 유저 획득 채널도 하나 더 생긴다
- [ ] Play Console 계정이 없으면 $25(최초 1회) 결제
- [ ] Play에 **실제 공개**까지 완료 (비공개·내부테스트로는 GRAC DB에 안 올라감)
- [ ] GRAC "자체등급분류 게임물 조회"에서 검색되는지 확인 → 등록자명·사업자명·등급분류일자·번호 확보
- [ ] 앱인토스 콘솔 "게임 등급분류" → **"스토어 링크"** 옵션에 위 정보 입력
- [ ] 콘솔 이미지 규격이 Play와 다름 — 로고 600×600(투명 불가), 썸네일 1932×828, 스크린샷 636×1048 3장 이상
- [ ] 게임 주요화면은 반드시 실제 캡처
- [ ] **앱인토스에만 내야 하는 사정이 있을 때만** ② GRAC 직접 신청을 검토. 그때는 사업자등록이 선행 조건
